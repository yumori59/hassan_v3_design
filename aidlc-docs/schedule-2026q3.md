## 1. 律速はマージである (この認識が最優先)

**実測**: 実装リポの `origin/main` は 10 コミット・マージ済み PR 4 本 (8/03〜8/06) で、**8/06 以降のマージはゼロ**。
そのあいだに issue は 23 本に積み上がり、**レビューまで終わった #6 / #7 が 3 日滞留している**。
一方このスケジュールは **40 issue / 7.4 週 = 5.4 本/週**のマージを要求する。

止まっているのは実装ではなく **H-1 (人間の approve とマージ)** であり、
その機構であるブランチ保護・environment が未設定 (実装リポ rules 04 §4) であることと同根である。
**この 2 つを片付けない限り、下の表は絵に描いた餅になる。**

| 運用として決めること | 内容 |
|---|---|
| **マージの頻度** | **週 6 本以上**を維持する。滞留が 3 本を超えたら、その週は新規着手を止めてマージに充てる |
| **観測** | 週次で `gh pr list --state open` の本数と最古の PR の経過日数を見る。**「実装が進んでいる」を issue のクローズ数で測る** (ブランチの本数で測らない) |
