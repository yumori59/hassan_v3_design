### 重大 1. 判定ランク閾値 (8.8 / 8.0 / 7.0) の載せ替え根拠が、同じ文書が「採らない」と宣言した残骸行に依拠している — かつ決定的な出典が引かれていない (DR-1 / DR-7)

**対象**: `docs/design/API/ideas.md` §6.3.3「載せ替えの計算根拠」の 2 と 3 / §7 の **D-IDA-18** の却下 (c)

**設計の記述** (`docs/design/API/ideas.md:812`〜`:813`):

> 2. **加重の下限値は上限 5 → 上限 10 の線形変換 (×2) で載せ替える** — v4 の 4.4 / 4.0 / 3.5 が上限 5 の尺度であることは、
>    同じプロトタイプが加重総合を `verdict: "A・4.6"` (`:13421`) や「加重総合 4.6 で Decision-Ready」(`:11871`) と
>    表示していることから分かる。
> 3. **線形変換以外の再校正は行わない** — 通過率の設計 (どのくらい厳しいか) は **v4 の作者の運用判断**であり、
>    設計側で動かす根拠が無い。

**実物照合の結果 (一次ソース `docs/prototype/hassan_agent_prototype_v4.html`)**:

| 引かれた行 | 実測内容 | 問題 |
|---|---|---|
| `:13421` | `phase:{name:"A", …}, stars:5, stage:"企画作成", …, verdict:"A・4.6", verdictCls:"a",` | **同じモックブロックの `:13636` が `overallScore: 32` (旧 4 軸和)** であり、**本設計が §6.3.6 で「残骸として採らない」と名指しした当のデータ**である |
| `:11871` | `7 軸スコアの内訳を見ると… 市場規模・アセット適合性・差別化で 4.5 以上と突出。ミッションとの整合性（4.6）と技術実現性（4.4）も高く、加重総合 4.6 で Decision-Ready 判定。` | **「7 軸」「アセット適合性」「差別化」「ミッションとの整合性」** を含む = **§6.3.6 で残骸と判定した `:8161`「7 軸スコア (加重)」と同世代のテキスト**。しかも**軸スコア自体が 4.4〜4.6 の 0〜5 尺度**で書かれており、現行の 0〜10 アンカーとも整合しない |

**照合で見つかった、引かれていない決定的な出典**:

`docs/prototype/hassan_agent_prototype_v4.html:17634` — **`verdicts` テーブルを描画する直下の脚注**:

```
加重平均は 4 軸のスコア（10 点満点）を重みで加重し、5.0 満点に正規化した値です。
```

これは「軸は 10 点満点 / 加重平均は 5.0 満点に正規化」を**プロトタイプ自身が明示した唯一の記述**であり、
設計の ×2 という結論を**残骸に頼らず直接裏付ける**。**この行が引かれていない**。

**なぜ本番で問題になるか**:

1. **DR-1 / DR-7 の型**: 本増分の最も影響の大きい数値 (全アイデアのランクを決める 4 段の閾値) の根拠が、
   **同一文書が「仕様として採らない」と宣言した 2 行**である。読者 (実装リポの開発者) は §6.3.6 で
   「`:13636` のモックと `:8161` は残骸」と読んだ直後に、§6.3.3 で「`:13421` と `:11871` を根拠に閾値を決めた」と読む。
   **どちらを信じるかが読者に委ねられ、閾値の再検討が起きたときに根拠が崩れる**。
2. **決定 3 の主張が事実に反する**: `:17634` の脚注が **「4 軸」** と書いていることと、
   変更履歴 (`:17121` = 2026-08-16 に 3 軸化 / `:17124` = 2026-07-20 初版 4 軸) を合わせると、
   **4.4 / 4.0 / 3.5 は 4 軸時代に決められた値であり、3 軸化にあわせて再判定された痕跡が無い**。
   したがって「**通過率は v4 の作者の運用判断**であり設計側で動かす根拠が無い」は成立しない
   (**3 軸に対する運用判断は存在しない**)。合成尺度の構成が 4 軸 → 3 軸で変わっている以上、
   同じ閾値が同じ通過率を与える保証はない。
3. **アンカー下限 2 点との相互作用**: composite の値域は **2.0〜10.0** (§6.3.3 の却下 (b) が自ら指摘)。
   `C` = `[2.0, 7.0)` は値域の **62.5%** を占める。この配分が意図どおりかは
   **4 軸時代の閾値をそのまま倍にしただけでは検証されていない**。

**修正案** (いずれも設計書の記述の修正で足り、数値の変更は要求しない):

1. §6.3.3 の 2 の出典を **`docs/prototype/hassan_agent_prototype_v4.html:17634` (verdicts テーブル直下の脚注) に差し替える**
   (`:13421` / `:11871` は補強として残すなら「**残骸と同世代のテキストだが尺度の記述は一致する**」と明記する)
2. §6.3.3 の 3 を **「v4 の閾値は 4 軸時代 (`:17634` の脚注が『4 軸』のまま / 3 軸化は `:17121` = 2026-08-16) に
   決められた値であり、3 軸に対する再判定は行われていない」**に改める。そのうえで
   「**増分 1 では線形変換のみで持ち込み、再校正は IDA-R7 の A/B を根拠に行う**」という現在の判断は維持してよい
3. **再校正の起動条件を数値で書く** — §9 の **IDA-R7** に「判定ランクの分布」が既にあるので、
   **「C の比率が N% を超えたら `entity/idea` の定数を見直す」型の観測条件**を 1 行足す
   (D-IDA-18 の却下 (c) が「動かす根拠が無い」と書いている限り、観測しても誰も動かさない)
4. D-IDA-18 の却下 (c) の理由文を 2 と整合させる
