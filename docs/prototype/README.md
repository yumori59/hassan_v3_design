## 位置づけ (重要)

**プロトタイプは設計入力であって仕様ではない** (DR-7)。

- 画面に存在する挙動が、PoC のバックエンドに**実装されているとは限らない**
- プロトタイプの画面遷移・文言・データ形状を根拠に仕様を確定しない。
  確定は `docs/design/` の設計書と `aidlc-docs/inception/<feature>/requirements.md` で行う
- プロトタイプと設計が食い違う場合、**設計書が正**。プロトタイプ側は更新しないまま残ることがある

## 使い方

- UX の意図・情報設計・画面構成の**参照**として使う
- 設計書から参照する場合は「プロトタイプでは〜という体験を想定している」と、
  仕様ではないことが分かる書き方にする
